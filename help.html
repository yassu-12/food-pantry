質問の一覧

フードパントリーとは何ですか？

食品ロスを減らす取り組みとして始まった、食品の受け取り場所です。届いた食品を、ポイントと交換して受け取れます。地域連携教育推進センターが運営しています。

アプリを入れる必要はありますか？

いりません。スマホのブラウザ（Safari や Chrome）で動きます。登録も、名前や学籍番号の入力もありません。

ポイントはどうやってもらえますか？

初めて開いたときに 500ポイントもらえます。そのあとは、掲示してあるQRコードを読むと、そこに書いてあるポイントがもらえます。

  • 来所：500ポイント
  • 活動に参加：100・200・300ポイント（活動によって違います）
  • 期限が近い食品をもらう：25ポイント
ポイントが足りないときは、どうすればいいですか？

活動に参加すると、ポイントがもらえます。どんな活動があるかは、地域連携教育推進センターに聞いてください。

0ポイントの食品は、どう使いますか？

期限が切れた、またはもうすぐ切れる食品は、ポイントを使わずに持っていけます。持っていくときに、棚に貼ってあるQRコードを読むと、25ポイントもらえます。

ポイントや履歴は、どこに記録されますか？

このスマホのブラウザの中だけに記録されます。名前や学籍番号は記録しません。外部には何も送りません。

ポイントが消えることはありますか？

ポイントに期限はありません。ただし、ブラウザのデータを消したとき、ブラウザやスマホを変えたときは、ポイントと履歴が消えます。

LINE からQRコードを開いたら、ポイントが違いました。

LINE の中で開くと、Safari や Chrome とは別の場所に記録されます。QRコードは、スマホのカメラで読んで、Safari や Chrome で開いてください。

ここにない質問は、センターで気軽に声をかけてください。
